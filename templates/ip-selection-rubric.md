Score each candidate from 1–5.

| Criterion | Score |
|---|---:|
| One-sentence hook is clear | |
| Protagonist has contradiction and agency | |
| Story engine can generate 30+ chapters | |
| Visual identity is immediately distinct | |
| Conflict can escalate across volumes | |
| Supporting cast can sustain spin-offs | |
| Works as prose | |
| Works as manga/comic | |
| Has animation-friendly action or emotion | |
| Rights are original and documentable | |
| You can finish a pilot in 90 days | |

## Decision

Choose the highest-scoring property only if it also feels personally urgent to make. Commercial clarity without creative conviction will not sustain serialization.
