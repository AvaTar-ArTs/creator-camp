# Manga, Webtoon, and Comic Serialization

## Manga pilot

Target:

- 24–50 pages
- One complete emotional movement
- One central conflict
- 3–6 important characters
- A final hook for continuation

## Manga pilot structure

```
Page 1–3: visual hook
Page 4–8: protagonist and normal world
Page 9–15: disruption
Page 16–25: first attempt and failure
Page 26–35: power, choice, or revelation
Page 36–45: confrontation
Final page: irreversible hook
```

## Webtoon episode

Use vertical pacing:

- 40–80 panels
- Strong first-screen hook
- Short dialogue balloons
- Deliberate scroll pauses
- Clear mobile lettering
- One reveal or emotional beat per episode

## Page comic

Best for:

- Print manga
- KDP fixed-layout ebooks
- GlobalComix
- Digital storefronts
- Contest submissions

Preserve:

- Reading direction
- Bleed and safe margins
- Panel hierarchy
- Lettering consistency
- Layered source files
- Clean export masters

## Art-only submissions

For drawing contests or character-art recognition, prepare:

- 1–3 finished character plates
- Turnaround sheet
- Expression sheet
- Action pose
- Environment or faction image
- Short design rationale
- Originality and source statement

Do not submit only isolated pretty portraits. Show character function, silhouette, story context, and repeatability.

## Adaptation bridge

Create a correspondence table:

| Prose scene | Manga pages | Webtoon episodes | Animation sequence |
|---|---:|---:|---:|
| Curse selection | 3–5 | 1 | 45–75 seconds |
| First hunt | 8–12 | 2–3 | 3–5 minutes |
| Antagonist reveal | 2–4 | 1 | 60–90 seconds |
