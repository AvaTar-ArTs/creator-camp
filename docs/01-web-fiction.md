# Web Fiction Production Guide

## What web fiction is

Web fiction is prose published chapter-by-chapter online. It is ideal for testing premises, discovering characters, building an audience, and creating a source property for later light novels, manga, audio, or animation.

## Formats

### Traditional serial

A continuous novel released in chapters.

- 2,000–5,000 words per chapter
- 2–4 releases weekly
- 8–15 chapters prepared before launch
- Best for fantasy, progression, isekai, occult, and adventure

### Arc serialization

A self-contained story arc inside a larger saga.

```
Arc 1: The Curse Awakens — Chapters 1–12
Arc 2: The Necromancer's School — Chapters 13–25
Arc 3: The Crimson Court — Chapters 26–40
```

### Episodic supernatural fiction

Each installment resolves a local mystery while advancing the mythology.

- The Curse That Eats Names
- The Saint of Broken Mirrors
- The Poison Garden
- The Necromancer's Apprentice

### Progression fiction

Make advancement visible through ranks, abilities, forms, weapons, titles, factions, costs, and consequences. Power must create new problems rather than erase all tension.

## Chapter structure

```
Hook → immediate goal → character interaction → complication
→ escalation → mini-resolution or cliffhanger
```

## Launch package

- Series title
- One-sentence hook
- 100–150 word description
- Genre and audience tags
- Content warnings
- Cover
- 3–5 prepared chapters
- Release calendar
- Author bio
- Newsletter link
- Canon and rights record

## Platform fit

- Royal Road: progression fantasy, LitRPG, isekai, dungeon, long serials
- Tapas: novels and comics, mobile-friendly discovery
- Scribble Hub: experimental web novels and broad genre testing
- Own site: canonical archive and audience ownership
- Shōsetsuka ni Narō / Kakuyomu: Japanese-language routes requiring appropriate localization

## Metrics

Track chapter views, completion, follows, favorites, comments, returning readers, email signups, paid conversions, and geographic readership. Follower count alone is weak evidence.

## Example premise

> A curse-bearer chooses one supernatural affliction each night, but every curse permanently changes one memory.

A first season could contain:

1. The Selection
2. The Memory Tax
3. The First Hunt
4. The Poison Saint
5. The False Cure
6. The Curse Market
7. The Forgotten Name
8. The Necromancer's Offer
9. The Crimson Choice
10. The Cost of Survival
