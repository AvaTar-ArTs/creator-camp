## P2/P3 — consolidate or document

Meaningful tooling repositories should receive a one-page role record: problem, audience, inputs, outputs, run command, license, and canonical/reusable/experimental/upstream status. Empty or tiny repositories should be marked incubating, archived, superseded, or reserved.

## Public recognition checklist

- README explains the project in one minute.
- Demo, screenshots, or sample output exists where relevant.
- Authorship and upstream attribution are visible.
- Rights/provenance are recorded for art, text, music, models, and datasets.
- Reproduction or contact path is present.
- The repository links back to the relevant Creator Camp package.
