# Publishing and KDP Playbook

## Amazon KDP

KDP supports Kindle ebooks, paperbacks, hardcovers, novels, series, comics, graphic novels, and manga.

### Prose

Use a reflowable ebook manuscript in DOCX or EPUB. Prepare separate paperback and hardcover files when needed.

### Comics and manga

Use Kindle Create or Kindle Comic Creator for fixed-layout comic ebooks. Kindle Create can import PDF, PNG, or JPEG pages and add Guided View panels. Kindle Comic Creator supports manga/comics page navigation and double-page spreads.

### Production stack

```
Prose ebook → EPUB/DOCX → Kindle reflowable
Manga ebook → PDF/PNG/JPEG → Guided View
Paperback → print-ready PDF
Hardcover → high-resolution print PDF
```

### KDP Select

KDP Select is optional. It can add Kindle Unlimited and promotional benefits, but enrollment creates ebook exclusivity during the enrollment period. Decide between:

- **Amazon-first:** KDP Select, KU, promotions
- **Wide:** KDP plus Kobo, Apple Books, Google Play, libraries, and direct sales

Do not enroll an ebook in Select while distributing the same ebook elsewhere.

## Wide distribution

- Kobo Writing Life: ebooks and audiobooks
- Draft2Digital: wide ebook and paperback distribution
- IngramSpark: bookstore/library-oriented print distribution
- Direct store: signed books, bundles, bonus files, memberships

## Edition strategy

```
Free serial edition
→ revised commercial ebook
→ paperback
→ hardcover collector edition
→ artbook or omnibus
```

The commercial edition should be edited, restructured, illustrated, and materially improved over the public serial.

## Metadata checklist

- Title and subtitle
- Series name and volume number
- Author name
- Description
- Categories
- Keywords
- Age range
- Content warnings
- Reading direction if relevant
- Edition statement
- ISBN plan
- Rights territories
- Contributor credits

## Quality control

Preview every edition on:

- Phone
- Tablet
- E-reader
- Desktop reader
- Print proof

Check gutters, crop, bleed, page order, reading direction, font size, image resolution, chapter navigation, and linked editions.
