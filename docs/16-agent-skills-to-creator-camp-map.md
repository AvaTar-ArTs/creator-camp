# agent-skills to Creator Camp Capability Map

## Purpose

This map translates the general-purpose agent and skill catalog into a creator/IP production system.

## Production lifecycle

### 1. Discover

Use research, workspace-ecosystem-audit, ecosystem-navigation, filesystem-inventory, and path-list-analyzer.

Outputs:

- repository inventory
- source ledger
- candidate projects
- duplicate and risk report
- open questions

### 2. Select

Use capability-atlas, ecosystem-clarity, narrative-blueprints, and project-launch-manager.

Outputs:

- flagship IP decision
- audience hypothesis
- format decision
- production scope
- rejected alternatives

### 3. Author canon

Use narrative-documentation, writing-skills, content-creator, visual-storyteller, and the choTaku canonist/d dramaturge concepts.

Outputs:

- logline
- storyworld
- character psychology
- lore
- timeline
- relationships
- scene contracts
- rights records

### 4. Produce

Use creative, media, sora, design-taste-frontend, frontend-design, and choTaku panelwright/forge concepts.

Outputs:

- character plates
- environments
- manga pages
- webtoon episodes
- illustrations
- storyboards
- prompts and provider manifests

### 5. Verify

Use verification-before-completion, red-teaming, receiving-code-review, test-results-analyzer, and the choTaku gatekeeper concept.

Outputs:

- continuity review
- identity-drift review
- rights review
- typography and layout review
- release checklist
- unresolved risk register

### 6. Publish

Use project-launch-manager, studio-producer, growth-hacker, social-media, github, project-shipper, and narrative-blueprints.

Outputs:

- release package
- platform metadata
- announcement assets
- submission packet
- audience metrics
- change log

### 7. Evolve

Use ecosystem-intelligence, self-improvement, self-evolving-memory, feedback-synthesizer, and the choTaku archivist concept.

Outputs:

- post-release review
- reader feedback synthesis
- canon amendments
- versioned assets
- next-arc plan
- capability gaps

## Recommended Creator Camp skill profiles

| Profile | Load first | Avoid loading by default |
|---|---|---|
| IP selection | narrative-blueprints, capability-atlas, ecosystem-clarity | unrelated platform access |
| Web fiction | writing-skills, narrative-documentation, feedback-synthesis | full engineering pack |
| Manga pilot | creative, media, visual-storyteller, verification-before-completion | business automation |
| Rights audit | research, workspace-ecosystem-audit, legal-compliance-checker | social growth |
| KDP release | narrative-blueprints, project-launch-manager, metadata workflow | experimental model skills |
| Anime pitch | narrative-documentation, visual-storyteller, studio-producer, rights audit | unrelated coding profiles |
| Repository audit | ecosystem-intelligence, ecosystem-navigation, filesystem-inventory, path-list-analyzer | creative generation |

## Skill-to-artifact contract

Every selected skill should identify:

- Trigger
- Inputs
- Output artifacts
- Canon impact
- Rights impact
- Validation step
- Next handoff
- Reusable evidence

This prevents a skill from becoming a vague narrative about a previous task.

## Creator Camp implementation recommendation

Add a future profile manifest with:

- profile ID
- skill IDs
- agent IDs
- required inputs
- output types
- validation gates
- provider dependencies
- publication targets

The profile manifest should be smaller than the full agent-skills catalog and should be versioned with each Creator Camp release.
