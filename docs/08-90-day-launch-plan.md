# 90-Day Creator Camp Launch Plan

## Days 1–15: choose and define

- Select one flagship IP
- Write the logline
- Define protagonist, antagonist, and central contradiction
- Create the power/cost system
- Build the first arc
- Complete the IP selection rubric
- Start the rights inventory

## Days 16–35: build the source

- Write 20,000–30,000 words
- Complete 8–15 chapter backlog
- Produce cover
- Produce 6–10 illustrations
- Create character and world bibles
- Set up owned landing page and newsletter

## Days 36–60: serialize

- Publish three chapters weekly
- Use one discovery platform
- Publish selected art and lore
- Collect reader reactions
- Track completion and return readers
- Avoid changing canon impulsively

## Days 61–75: adapt

- Select the strongest arc
- Write manga script
- Thumbnail 30–45 pages
- Produce 5 polished preview pages
- Create a webtoon adaptation sample
- Draft audiobook or motion-comic excerpt

## Days 76–90: package and submit

- Revise the first volume
- Format ebook and print edition
- Prepare submission packet
- Submit to appropriate opportunities
- Publish the commercial edition
- Record analytics and reader evidence
- Open a professional rights contact channel

## Success criteria

At day 90, you should have:

- A complete prototype
- A public release history
- A revised commercial edition
- A visual sample
- A rights/provenance record
- Audience evidence
- A repeatable production calendar
- A credible next-step pitch
